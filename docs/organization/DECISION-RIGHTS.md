# Decision rights

| Decision | Accountable |
|---|---|
| Technical and platform strategy | Human CTO |
| Executive decision coordination | Chief of Staff |
| Portfolio strategy recommendation | Product Director |
| Issue-level accepted requirements | Product Owner |
| Platform-wide architecture standards | Chief Architect, within CTO governance |
| Feature architecture | Solution Architect |
| Detailed solution specification | Solution Designer |
| UX design | UX / Product Designer |
| Implementation | Developer |
| AI engineering design | AI / Agentic Systems Engineer |
| Test verification | QA Engineer |
| Independent benchmark methodology | Benchmark & Evaluation Engineer |
| Security findings | Security Engineer |
| Security risk acceptance | Human CTO |
| Privacy and legal risk acceptance | Human CTO (Privacy specialist advises; not legal counsel) |
| Production orchestration | Production Director |
| Operational readiness | DevOps and SRE within their scopes |
| Release recommendation | Release Manager |
| Release authorization | Human CTO |

Always CTO-only: spending and subscriptions, model/provider policy (including any extra Opus use), public capability claims, external customer contact, licensing and IP, agent permissions, organizational policy changes, installing third-party skills that need new dependencies or carry share-alike licenses.

Rules: no agent approves its own implementation; an agent review is not an independent human review; a title (Chief, Director, Owner, Manager) confers no CTO authority; Advisor output is never an approval ([ADVISOR-POLICY](ADVISOR-POLICY.md)).
